# Map data sources

Everything in `maps/*.json` comes from the sources below, put together by `build_maps.py`. Nothing is drawn from memory or guessed. If no source places a stairwell, restroom, elevator or room, it isn't on the map, and the page says it's missing. Downloads were made on 2026-10-13.

## Sources used

| Key | Source | What it gives | How exact |
|---|---|---|---|
| `osm` | [OpenStreetMap](https://www.openstreetmap.org/copyright) (ODbL), raw API 0.6 `map?bbox=` calls over campus, the Hill and the Southwest apartments, split into 42 tiles | Building outlines (mostly LA County building footprints), doors tagged `entrance=*` (some with `level`, `wheelchair`), stair doors (`entrance=staircase`), `highway=steps`, a few `highway=elevator` and `amenity=toilets` | Outlines are good to about 1 m. OSM's `level` numbers don't always match UCLA floor numbers, so the page shows them as "level N in OSM". |
| `ucla_gis` | UCLA campus map GIS, `https://map.ucla.edu/arcgis/rest/services/` (public layers, no login) | `data/location_area/MapServer/0`: building outlines. `data/data/MapServer/2`: floor counts. `data/feature/MapServer/0`: gender inclusive restrooms with building, room number, floor and position | Restroom points have distinct positions per room and stack floor over floor, so they look like room centers from UCLA's space data. |
| `c3d` | UCLA's interactive campus map, [maps.ucla.edu](https://www.maps.ucla.edu/?id=2043) (Concept3D map 2043, read through `api.concept3d.com` with the public key the web app uses) | Accessibility survey: 182 powered doors, 323 unpowered doors, 32 outdoor/entrance elevators, 138 accessible restrooms. Each has a detail record (building, door type, side of building, approach: ramp/stairs/flat, access restrictions, restroom gender) | Surveyed points. A few doors sit well inside the outline (on a bridge or podium, or placed loosely); those are drawn as approximate with a note. Some restroom points share one spot for a whole building; those are listed but not drawn. |
| `ucla_pdf` | [UCLA Campus Accessibility Map, Oct 2020 (PDF)](https://map.ucla.edu/downloads/pdf/Access_Oct_2020.pdf) | Elevator dots (purple), accessible entrance dots (green), power assisted entrance dots (red) | The PDF has no coordinates. `build_maps.py` georeferences it: an affine fit from 75 PDF building shapes to their OSM outlines (median error 6.5 m), then a local correction from nearby matched buildings. Checked against surveyed doors: the green/red dots land a median 6.8 m from the nearest surveyed or OSM door. So these are approximate, about 7 m, and the page draws them with a dashed ring. Entrance dots are only used where no surveyed or OSM door is within 15 m. |
| plan | [UCLA Library, YRL Research Commons map (2024)](https://calendar.library.ucla.edu/reserve/yrl_gsr), image `2024_Updated_-_YRL_RC_Wall_Map.png` | Group study rooms G01 to G15, collaboration pods R01 to R20, RC Classroom, Data Science Center, PDF Center, Lux Lab, Laptop Lending, restrooms, unlabeled blocks, crossed boxes (no legend; they look like elevators and are labeled that way, with the caveat) | Rooms were traced from the image by color with `trace_plan.py` (`maps/plans/YRL-1.control.json`; OCR read the labels, the pods and crossed boxes were placed by hand). This covers only the Research Commons part of floor 1. |

The traced floor plans (the table below) add these publishers: UCLA Housing's legacy room sign-up plans (`www.housing.ucla.edu/maps/`), UCLA Conferences & Catering venue plans, the UCLA International Institute, the UCLA Library's Powell and YRL floor plan PDFs and the School of Music's plans (both from Common Crawl copies of pages since taken down), the Samueli School's "BH and MS" sheets (Common Crawl), the Semel Institute's Emergency Action Plan (CHS evacuation plans), UCLA IoES student reports (PAB, Perloff), CAP UCLA (Royce), and three architects' portfolios (STUDIOpractice for Broad, Pei Cobb Freed for Rosenfeld, Paul Murdoch for Young Hall 4), whose drawings are copyrighted and used here as reference only. Each control file in `maps/plans/` cites its page, file, date and access date.

The campus map tab uses OpenStreetMap tiles (`tile.openstreetmap.org`) through Leaflet 1.9.4 from cdnjs, with SRI hashes checked against the files and the cdnjs API.

The Directions button uses `https://maps.apple.com/?daddr=LAT,LON&dirflg=w` on iPhone, iPad and Mac, and `https://www.google.com/maps/dir/?api=1&destination=LAT,LON&travelmode=walking` everywhere else (Google's [Maps URLs](https://developers.google.com/maps/documentation/urls/get-started): `api=1` is required, `travelmode=walking` is documented, and the link opens the Google Maps app on Android and iOS when it's installed). Apple's current docs describe newer [unified Maps URLs](https://developer.apple.com/documentation/mapkit/unified-map-urls) (`/directions?destination=...&mode=walking`) that need iOS 18.4 or later; the older `daddr`/`dirflg=w` form is used because it also works on older iPhones. On Android there is also an "Other app" `geo:` link. The destination is the building point from `buildings.json`, or the outline's center if that point is more than 30 m off the outline.

## Traced floor plans

Rooms, corridors, stairs and walls are only drawn where a published plan exists. `trace_plan.py` traces each plan (see the top of that file for how), fits it to the ground with control points, and writes a floor record to `maps/plans/<CODE>-<floor>.json`. The control file next to it (`<CODE>-<floor>.control.json`) holds the plan's source, the control points and every hand fix, so a trace can be rerun. The table below is rewritten by `trace_plan.py` and `build_maps.py`. Residuals are the distance in metres between where the fitted plan puts each control point and where the source puts it.

Notes on the plans used:

- **Room floors**: `maps/rooms_index.json` is UCLA Space Inventory's public room list per floor (spaceinventory.ucla.edu, building and floor records need no account), fetched 2026-10-13 for 29 buildings. The floor picker and the room note use it first; the room number rule is the fallback. It also lists each floor's stair and elevator rooms (the ST and EL entries).
- **Boelter Hall** floors 1 to 9 are UCLA Space Inventory plans, published as screenshots in the public repository [github.com/tiffanyzhoujh/BoelterNavApp](https://github.com/tiffanyzhoujh/BoelterNavApp) (2025). The repository has no license file; the drawings are UCLA's. Floor 2 is fitted to the building outline; the other floors are lined up with floor 2 through their stair and elevator labels, which stack floor over floor.
- **Young Hall** floor 2 is a phone photo (2026-10-12) of the evacuation plan posted on that floor. The sign is schematic (its wings are drawn narrower than they are), so after the outline fit it is stretched along the building grid; the table gives the fit before and after.
- **Young Hall** floor 4 is the architects' plan from Paul Murdoch Architects' 2019 feasibility study (their portfolio page; copyright theirs). Walls, corridors, stairs, elevators and restrooms, no room numbers. Fitted to the outline and checked against the floor 2 cores.
- **Bunche Hall** floor 10 is the International Institute's own floor map (CAD plan, March 2006) on international.ucla.edu. The tower footprint is symmetric end to end, so the orientation is set so that UCLA's stacked restroom records (x253, x257, x350 on floors 3, 4 and 8) fall by the plan's restrooms at the elevator core. The other floors of Bunche have no public plan.
- **Powell Library** floors 0 to 3 are the UCLA Library's own "Powell Library Building Floorplans" PDF (vector, all four floors on one sheet, room numbers). The Library took it down; the copy is from Common Crawl's March 2018 crawl of `library.ucla.edu/sites/default/files/Powell-floorplan-color_link_0.pdf`. It replaces the LibCal Media Lab map for floor 2 (that control file is kept under `plans/retired/`). The three CLICC classrooms share one label on the plan, so 307, 320 and 320B are drawn without numbers.
- **YRL** floors 2 to 5 are the Library's schematic "Floor Maps" PDF (Common Crawl, October 2019), block shapes with stair, elevator and restroom icons and no room numbers; the A level diagram didn't fit the footprint and isn't used. Floor 1 stays as before (2024 Research Commons map plus the 2016 map).
- **Schoenberg Music Building** floors 1 and 2 are the School of Music's plans (room numbers, scale bar, north arrow), recovered from Common Crawl's September 2017 crawl of music.ucla.edu. Floor 2 is fitted to the outline; floor 1 is stacked on floor 2 through three stairs read on both sheets.
- **Math Sciences** floors 1 to 5 are the Samueli School's "BH and MS" sheets (2010-2011, scanned; each sheet shows Math Sciences above Boelter at one scale), recovered from Common Crawl's December 2018 crawl. The sheet's scale and rotation come from fitting its Boelter half to the traced Boelter floor through room numbers (max 1.3 to 2.4 m); only the position is then fitted to the Math Sciences outline. Only floor 2's room numbers are legible; floors 1, 3, 4 and 5 are rooms and corridors without numbers, and floors 6 to 8 have no plan. UCLA's restroom record 2922 lands 11 m from the traced 2922, which is unexplained.
- **Physics and Astronomy** level 1 and **Perloff Hall** B, 1 and 2 are floor plans reproduced in UCLA IoES student reports (Energy Team 2015 appendix, a scan of a UCLA "Physics-Astronomy Level 1" plan with a scale bar; Energy Team 2023, UCLA Energy Services building-automation floor graphics). The room numbers were typed from the plans. PAB's east edge is cut off on the scan.
- **Broad Art Center**: one sheet from STUDIOpractice's portfolio (the Richard Meier & Partners 2006 drawings; copyright theirs) with a scale bar and no room numbers; the main building is floor 1 and the south wing on the same sheet is floor 2 (UCLA's restroom records 1276 and 2113 land in each part's restroom block). The other sheets couldn't be tied to UCLA floor numbers and aren't used.
- **Center for Health Sciences** levels A, B, C and 1 are the CHS evacuation plans (December 2008 and 2009) attached to the Semel Institute's Emergency Action Plan (space.semel.ucla.edu). Fitted on six UCLA GIS restrooms (max 1.9 m, which agrees with the scale bar). The plan numbers rooms corridor-first (12-077); the Biomedical Library rooms are labeled by hand.
- **Rosenfeld Library** levels 1 to 4 are Pei Cobb Freed & Partners' presentation plans of the Anderson complex (their project page; copyright theirs), cropped to the library wing. No room numbers. The architects' Level 1, Ground, Level 2 and Level 3 are taken as UCLA floors 1 to 4 from the drawings and the Anderson complex map; the titles say this is uncertain.
- **Royce Hall** stage level is CAP UCLA's rental ground plan (2020, stated 3/8" = 1'), placed on the building's symmetry axis at the stated scale; only the stage house and the front of the house are drawn.
- **Covel Commons** (floor 3), **Carnesale Commons** (2 and 3) and **De Neve Commons** (1) are UCLA Conferences & Catering's venue floor plans (room names, no numbers), fitted on outline corners. The De Neve level is an inference from the room list (the control file says why). The site's numbered rooms in these buildings can't be matched to names.
- **The Hill and the Southwest apartments** are UCLA Housing's legacy room sign-up plans, still served at `www.housing.ucla.edu/maps/` and linked from housing.ucla.edu's "Housing Building Maps" page: Olympic Hall 1 to 9 (2021 CAD, room numbers, verified against UCLA GIS restrooms OH227, OH262, OH327, OH427 and OH456), Hedrick, Rieber and Sproul floors 2 to 7 by wing (2002 CAD, room numbers; wing corners fitted on outline vertices, orientation checked against GIS restrooms and the elevators), Gayley Heights 1 to 17, Tipuana 1 to 9, Laurel 1 to 8 (two half sheets per level, joined before the fit) and Palo Verde 1 to 8 (2024-2025 CAD, apartment numbers), Hitch Suites A to D, and Canyon Point. None of these plans has a scale bar; the outline fit sets the scale. Hedrick, Rieber and Sproul floor 1 (where the study rooms are), Hedrick Summit, Rieber Terrace and Vista, Sproul Cove and Landing and the De Neve residential buildings have plans too but their footprints aren't in this map's outlines, so they aren't traced. Canyon Point's eight houses are near-identical and the outline fit can't tell which slot of the ring a house belongs in; only House 1 (floor 1) lands by its entrance and is kept. Gayley Heights' fit is approximate (about 4 m) because the plan's sidewalks merge with the footprint. The housing plans' OCR reads this CAD font's 2 as 8 (254 reads 854); numbers whose first digit isn't the floor were corrected by hand and each correction is recorded in the control file.
- **Olympic Hall** site rooms 375B to 375D and 470/475 and **Hitch** 100 are not numbered on the plans (they say GROUP STUDY / OPEN STUDY), so they can't be placed even though their floors are traced.

## Floor from the room number

UCLA rooms are mostly numbered with the floor first: Boelter 2444 is on floor 2, Math Sciences 5200 on floor 5. `floor_of()` in `build_maps.py` and `floorOf()` in `maps.js` apply that rule:

- Registrar numbers are zero padded (`02444`, `A00152`). Padding is dropped first.
- 3 or more digits: the first digit is the floor (`2444` is 2, `148` is 1, YRL `11368A` is 1).
- 1 or 2 digits: level 0 (UCLA lists Powell `29B` on floor 0). Dodd 78 and Haines 39 use this.
- A letter prefix of A, B, C or M is the floor itself (A-level, B-level). UCLA's restroom records use those letters as floor names.
- Olympic Hall numbers start with `OH` (a wing prefix, `OH107` is floor 1). CHS numbers like `AL213` start with the floor letter.
- Anything else (Young Hall `CS24`, De Neve `P350`) gives no floor. The page says it can't tell.

Each building file records how many UCLA restroom records (which list both a room number and a floor) agree with the rule. The page shows that count, and if the rule fails anywhere in a building it says "probably". Canyon Point fails (UCLA lists room 5103 on floor 1), so its floors are marked uncertain. Some people say Boelter's second digit is the hallway; that isn't from UCLA, so it isn't used to place rooms.

## Rebuild

```bash
pip install pdfplumber
python maps/build_maps.py            # uses maps/.cache if it's there (git-ignored)
python maps/build_maps.py --refresh  # download everything again
```

To add a traced plan, write a control file in `maps/plans/` like `YRL-1.control.json` (building code, floor, source URL and date, 2 to 4 control points pairing plan pixels with something a source above places, like a UCLA restroom or a corner of the outline, and any hand fixes) and run `python maps/trace_plan.py` on it. It writes the floor record `maps/plans/<CODE>-<floor>.json`, which `build_maps.py` merges on every rebuild.
